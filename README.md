# RDB Website Redesign – Regional Development Bank

A redesign and full-stack rebuild of the Regional Development Bank (RDB) website, focused on improving user experience, modernizing the interface, and delivering a more intuitive digital banking website.

## Overview

This project involved redesigning and developing a banking website for the Regional Development Bank, with an emphasis on improving the user experience, visual hierarchy, navigation, and overall interface usability.

The project progressed from UI/UX prototyping to implementation, transforming the redesigned concepts into a functional website using web technologies.

## Technologies

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js
- **Database:** MongoDB

## Objectives

- Redesign the existing banking website with a modern interface.
- Improve navigation and information organization.
- Enhance usability through better layouts and visual hierarchy.
- Translate UI/UX prototypes into a functional web application.
- Implement backend functionality and database integration.

## Project Highlights

- UI/UX redesign and prototyping
- Website interface development
- Frontend and backend implementation
- Database integration
- User-focused design improvements
